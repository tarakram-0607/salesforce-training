->Day 5 - Apex Introduction

* What is Apex?
Apex is Salesforce’s programming language used for advanced business logic and automation.

* Flow vs Apex
-> Flow
- No-code automation
- Easy to build
- Used for simple business logic
-> Apex
- Requires coding
- Used for advanced logic
- More flexible and powerful

* Configuration vs Coding

Configuration uses clicks and settings.
Coding uses Apex programming for complex requirements.

* Examples Where Apex is Needed

1. Complex fee calculation
2. External payment integration
3. Advanced eligibility checking

* Integrated College Management System
