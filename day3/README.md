 Difference Between
*App
Collection of tabs and features.

*Object
Database table.

*Record
Single row of data.

*Field
Column inside object.

->Standard vs Custom Objects
*Standard Objects:
Objects already provided by Salesforce like Account and Contact.
*Custom Objects:
Objects created by users based on business needs like Student or Course.

-> College Data Model
Objects:
- Student
- Faculty
- Course
- Department
Relationships:
- Department → Student
- Department → Faculty
- Course → Student

-> Formula Fields

2. Age cannot be negative
