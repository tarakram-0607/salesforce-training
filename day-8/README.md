-> Day 8 - Lightning Web Components (LWC)
-> What is LWC?
LWC (Lightning Web Components) is Salesforce’s modern UI framework used to build fast, reusable, and component-based applications using HTML, JavaScript, and Metadata XML.

-> Why Salesforce Uses LWC
Salesforce uses LWC because it provides:
- Better performance
- Reusable UI components
- Modern frontend architecture
- Faster development
- Cleaner code structure

---

## Frontend vs Backend

### Frontend (UI)
Handles:
- Buttons
- Forms
- Screen display
- User interaction

Examples:
- Student registration form
- Attendance dashboard
- Notification display

### Backend (Apex)
Handles:
- Database operations
- Business logic
- Validation
- Complex calculations

Examples:
- Fee calculation
- Attendance processing
- Eligibility checking
